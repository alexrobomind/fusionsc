C++ API Usage Examples

All types are in the fsc namespace.

Structs

Creating ReversibleFieldlineMapping:

fsc::ReversibleFieldlineMapping message;
message.set_r(...);

Creating Section:

fsc::Section message;
message.set_r(...);

Creating Inverse:

fsc::Inverse message;
message.set_rMin(...);

Interfaces

Using FLT:

// Get interface reference
auto interface = connection.get<fsc::FLT>();

// Call method: trace
auto result = interface.trace().wait();

Using Mapper:

// Get interface reference
auto interface = connection.get<fsc::Mapper>();

// Call method: computeRFLM
auto result = interface.computeRFLM().wait();
